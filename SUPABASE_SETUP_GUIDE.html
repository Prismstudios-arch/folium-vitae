🗄️Supabase Setup (5 minutes)

ℹ️ Info: This guide is copy-paste. Just follow the steps and you'll have a working database in 5 minutes.

1️⃣ Create Supabase Account

1
Go to Supabase: Open your browser and visit https://supabase.com
Click "Sign Up" (top right button)
Sign up with email:
  • Enter your email
  • Create a strong password
  • Click "Sign Up"
Verify email: Check your email inbox, click the verification link
✅ You're logged into Supabase!

2️⃣ Create Project

2
Click "New Project" (you'll see this on the dashboard)
Fill in the form:
Field Value to Enter
Project name verdure
Database password Verdure123!@# (make it strong)
Region US East (closest to you)
Pricing plan Free (perfectly fine)
Click "Create new project" and wait 2-3 minutes for it to initialize
ℹ️ Status page: You'll see "Initializing project..." → eventually you'll see a green checkmark when it's ready
✅ Project created! You now have a PostgreSQL database in the cloud

3️⃣ Get Your Connection String

3
Click "Settings" (bottom left of Supabase dashboard)
Click "Database" (in the left sidebar)
Look for "Connection String" section
Select "Postgres" tab (if there are multiple tabs)
Copy the connection string that looks like this:
postgresql://postgres:[YOUR-PASSWORD]@db.[YOUR-REFERENCE-ID].supabase.co:5432/postgres
⚠️ IMPORTANT: Replace [YOUR-PASSWORD] with the database password you created (e.g., Verdure123!@#)
Save this somewhere safe (you'll need it next)
✅ You have your connection string!

4️⃣ Save It for Later

4
Open Notepad and paste your connection string:
DATABASE_URL=postgresql://postgres:Verdure123!@db.xxxxx.supabase.co:5432/postgres
Save this file as: C:\Users\Jonny\supabase_connection.txt
✅ Your Supabase project is ready! Now go back to the setup guide.

✅ What You've Done

  • ✅ Created Supabase account
  • ✅ Created "verdure" project
  • ✅ Got your connection string
  • ✅ Saved it for next steps
ℹ️ Next step: You'll use this connection string in your .env file

❓ Stuck?

If you don't see "Connection String":
  • Make sure you're in Settings → Database
  • Look for tabs at the top (Postgres, URI, etc.)
  • Click "Postgres" tab
If project is still initializing:
  • Wait 2-3 more minutes
  • Refresh the page
  • Check for green checkmark
If you forgot your password:
  • Go to Settings → Database
  • Click "Reset database password"
  • Create a new one
  • Update your connection string
